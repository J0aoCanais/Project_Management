## 1. Âmbito

- `PageHeading` "Oportunidades" + **Nova oportunidade** (primário; abre `Drawer` com Imóvel/morada, Tipologia, Zona, Preço pedido, VVR e lead de origem opcional).

- **Quadro:** `KanbanBoard` com 8 colunas, uma por fase (numeração automática a partir de `startAt`, que aqui é 1; ponto colorido via `dotClassName`).
  - `DealCard`: `Pill` da tipologia, `DropdownMenu` ⋯, título, zona com ícone, Preço pedido e VVR, faixa "Lucro estimado", rodapé com "`n` dias nesta fase" (vermelho se passar o `maxDaysStalled` da fase; por omissão 10) e `Avatar` do responsável.
  - Arrastar um cartão para outra coluna chama `onMove`, que muda a fase (atualização otimista + mutation; se falhar, volta atrás e mostra erro). Também tem de ser possível mudar de fase **sem rato** (no `DropdownMenu` → "Mover para…").
  - Clicar no cartão abre `/oportunidades/:id`.
- **Lista:** `Table` com Imóvel / Zona, Tipologia, Preço pedido, VVR, Lucro estimado, Fase, Dias. Valores em euros com `align: "right"`.

### Detalhe (`/oportunidades/:id`)
- `EntityHeader` com `media` (ícone), `type` "Oportunidades · Registo atualizado …", título e `meta` (`Pill` da fase atual e "Responsável: …"). Ações:
  - **Gerar relatório** (secundário)
  - **Marcar como rejeitada/perdida** (perigo → `Dialog` com motivo obrigatório)

- `Tabs` (estado em `?tab=`): **Resumo**, **Análise financeira**, **Histórico de fases**, **Documentos**.
  - **Resumo:** painel "Informação principal" (Tipologia, Zona, Área, Preço pedido, VVR, Contacto, Data de visita) + Observações; ao lado, "Atividade recente" com `Timeline`.
  - **Análise financeira:** ver §3.
  - **Histórico de fases:** `Table` (Fase anterior, Nova fase, Data, Nota).
  - **Documentos:** `Notice` informativo (pode carregar em qualquer fase, incluindo due diligence; ficam associados ao imóvel e aparecem em Documentos), select do tipo de documento (Caderneta predial, Certidão permanente, Orçamento de obra, Planta, Licença de utilização, Certificado energético, Outro), `FileUploadButton` **Carregar documentos** (com `multiple`) e `Table` (Documento, Tipo, Imóvel, Entidade associada, Tamanho, Validade, Estado). Vazio → `EmptyState` "Ainda não há documentos."
- **Relatório:** pré-visualização em ecrã inteiro (portal para `document.body`) com barra "Fechar / Imprimir / guardar PDF" (`window.print()`); estilos de impressão com as variantes `print:` do Tailwind (esconder app e barra, mostrar só o relatório). Conteúdo: cabeçalho com título e data, 2 fotos, KPIs (Investimento total, Venda prevista, Margem estimada, ROI, ROI anualizado, Prazo), "O imóvel", "Estratégia" e "Estrutura de custos" com total. Fecha com Esc (`useEscape`).
- Em telemóvel, o botão do relatório aparece como bloco de largura total abaixo do cabeçalho ("Gerar relatório para investidores").

- `finance.ts`: `calcFinance(values, extras)` igual ao mockup:
  - `outros = Σ extras.value`
  - `comissão = venda × comissão% × (1 + IVA%)`
  - `custo total = compra + IMT + selo + escritura + obra + outros + comissão`
  - `margem = venda − custo total`; `ROI = margem / custo total`
  - `ROI anualizado = (1 + ROI)^(12 / meses) − 1`
  - Divisões por zero devolvem 0 (ou "—" na UI).

## 3. Análise financeira

- **Pressupostos** (`NumberInput` dentro de `FormField`): Preço de compra, IMT, Imposto do selo, Escritura e registos, Custo da obra, Preço de venda previsto, Prazo previsto (meses).
- **Comissão imobiliária:** Comissão (%) — por omissão **5%** — e IVA sobre a comissão (%) — por omissão **23%**; valor calculado mostrado ao lado com a fórmula (`5% × 355 000 € + IVA 23%`).
- **Outros custos:** lista editável (descrição + valor), remover linha (`aria-label="Remover custo"`), **Adicionar custo** e total.
- **Cartão de resultados** (escuro, como `.results-card`): Investimento total, decomposição (Compra; IMT, selo e escritura; Obra; Comissão imobiliária c/ IVA; Outros custos), **Margem estimada** em destaque com % sobre a venda, ROI e ROI anualizado, e `Pill` "Rentabilidade acima do objetivo" (ROI > 15%, verde) ou "Rever pressupostos" (âmbar).
- Tudo recalcula **em tempo real** ao escrever. Guardar com botão **Guardar análise** (mutation `PUT …/finance`); avisar se sair do separador com alterações por guardar.
- Em ≤1050px o cartão de resultados passa para baixo do formulário; em ≤720px o formulário fica numa coluna.

```ts
export interface OpportunityCard {
  id: number;
  title: string;          // morada/nome do imóvel
  zone: string;
  typology: string;       // T1, T2…
  askingPrice: number;
  vvr: number;
  estimatedProfit: number;
  phaseIndex: number;     // 0–7, índice em OPPORTUNITY_PHASES
  daysInPhase: number;
  owner: { name: string };
}

export interface FinanceValues {
  purchasePrice: number; imt: number; stampDuty: number; deedCosts: number;
  workCost: number; expectedSalePrice: number;
  commissionPercent: number; commissionVatPercent: number; termMonths: number;
}
export interface ExtraCost { id: string; label: string; value: number }

export interface OpportunityDetail extends OpportunityCard {
  property: { code: string; areaM2: number; visitDate?: string; notes?: string; constructionYear?: number; condition?: string; energyCertificate?: string };
  contactName?: string;
  updatedAt: string;
  finance: FinanceValues;
  extraCosts: ExtraCost[];
  phaseHistory: { from: string; to: string; date: string; note?: string }[];
  activity: { date: string; text: string }[];
  documents: { id: string; name: string; type: string; propertyCode: string; entity: string; sizeBytes: number; validUntil?: string; status: string }[];
}
```
