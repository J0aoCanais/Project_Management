## 3. Dados

`src/api/dashboardApi.ts`:

```ts
export interface DashboardSummary {
  stats: {
    openOpportunities: { value: number; meta: string };
    activeOperations: { value: number; meta: string };
    yearSales: { value: number; meta: string };      // euros
    realizedMargin: { value: number; meta: string };  // euros
  };
  investorCapital: { total: number; committed: number; invested: number; available: number };
  funnel: { phase: string; count: number }[];          // 8 fases, pela ordem do prompt.md §7
  leadsBySource: { source: string; count: number }[];  // últimos 7 dias
  operationsByPhase: {
    phase: string;
    capitalSubtotal: number;
    operations: { id: string; code: string; zone: string; capital: number; margin: number }[];
  }[];
  alerts: { id: string; date: string; record: string; description: string; to: string }[];
}
export async function getDashboard(): Promise<DashboardSummary>;
```

- Fixture em `src/api/fixtures/dashboard.ts` com os valores do mockup (24 oportunidades, 8 operações, 1 285 000 €, 286 450 €, capital 1 240 000 € = 680 000 + 390 000 + 170 000, etc.), com `// TODO: trocar pelo endpoint quando existir`.
- Hook `src/hooks/useDashboard.ts` com `useQuery({ queryKey: ["dashboard"], queryFn: getDashboard })`.
- Os valores em euros chegam como **números** e são formatados no componente com `formatMoney`; percentagens com `formatPercent`.
- As rotas dos alertas usam as rotas do `prompt.md` §4 (`/leads`, `/obras`, `/oportunidades`, `/documentos`).

## 4. Layout e responsivo

- **Desktop (≥1051px):** stats em 4 colunas; funil e leads lado a lado; operações e alertas lado a lado.
- **Ecrã pequeno (721–1050px):** stats em 2 colunas; os painéis empilham.
- **Telemóvel (≤720px):** stats em 2 colunas compactas, tudo numa coluna; o funil mantém as 8 barras e faz scroll horizontal (já tratado pelo `VerticalBarChart`).
- Números sempre com `tabular-nums`.
